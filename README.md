# Gab Portfolio

A learning portfolio built with React, CSS, and Vite. The page introduces me as an IT student interested in networking and programming.

## Run it locally

1. Install dependencies with npm ci.
2. Start the development server with npm run dev.
3. Open the local address shown in the terminal.
4. Edit one section at a time in src/components/.
5. Create a production build with npm run build. Vite writes the deployable site to dist/.

## Deploy to GitHub Pages

This repository is for the root site https://llacuna750.github.io/, so Vite uses / as its base path.

The Deploy portfolio to GitHub Pages workflow builds and publishes the site when a change is pushed to main or portfolio-deploy. In the repository Settings → Pages, set Source to GitHub Actions.
